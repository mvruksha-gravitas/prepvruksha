# Localisation

- `app_en.arb` is the template. Add every user-facing string here first.
- `app_kn.arb` holds Kannada. **All Kannada strings are AI-drafted and need
  review by the Kannada translator before public launch.** When a string is
  reviewed, list its key under "Reviewed" below.
- Generated code is in `generated/` (run `flutter gen-l10n` from `apps/app`, or
  any `flutter run` / `flutter test`). It is committed so analysis works in CI.
